# Лійка — CRM лідів

`liika.html` — вихідний код CRM-дошки (воронка лідів для інвестиційної нерухомості),
опублікованої як Claude Artifact: https://claude.ai/code/artifact/ff5c95ca-f391-4615-b23c-95756576136c

Дані лідів зберігаються в базі артефакту (Claude `db` capability), а не в цьому репозиторії —
цей файл лише версіонує код сторінки. Щоб оновити живу версію після правок тут,
опублікуйте файл повторно на ту саму URL через artifact-інструмент з тим самим `url`.

Стадії воронки: Холодна база → Кваліфікація → Якісний лід → Інвестор · Оффер → Клієнт.
